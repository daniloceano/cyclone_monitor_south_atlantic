Known Discrepancies and Notes
──────────────────────────────────────────────────────────────────────
  • The Zenodo record for the wind100 dataset (DOI: 10.5281/zenodo.
    19353037) states coverage for 1979–2020. However, a local folder
    '2021_wind100' is present and has been processed. The 2021 data
    contains 1 track (20210007), which is consistent with the main
    dataset ending on 2021-01-07. This is treated as valid data.

  • wind100 track IDs may not fully overlap with the main dataset.
    Differences arise from distinct filtering thresholds between the
    two datasets. See 'Tracks in wind100 ONLY' count above.

  • LEC energetics in the main dataset are 3-hourly interpolated to
    1-hourly. The 'lec_original' flag (True = original 3-hourly value)
    is preserved in all output files.

  • wind100 data are 1-hourly. No interpolation is applied to wind100
    columns. NaN is preserved where no wind100 record matches.

  • Timezone: all timestamps are UTC-naive in both datasets. No tz
    conversion is applied.
