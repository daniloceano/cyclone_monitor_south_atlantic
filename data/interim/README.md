# data/interim/

This directory holds intermediate data products: files that are neither raw
input nor the final per-cyclone product, but are needed as inputs to later
pipeline steps or as reference artefacts.

## Contents

Currently empty. Intermediate files are generated on demand by the pipeline
scripts and are gitignored (large binary files).

## Notes

- All files here are **regeneratable** from `data/raw/`. Never commit large
  binary files to this directory.
- If a future step requires a year-level merged Parquet (all tracks for one
  year merged with wind100), it would live here as
  `tracks_{YYYY}_with_wind100.parquet`.
- The per-cyclone final product lives in `data/processed/tracks_by_id/`, not
  here.
