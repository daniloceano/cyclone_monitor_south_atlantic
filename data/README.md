# Data Directory

This directory contains all datasets used by the South Atlantic Cyclone Monitor.

## 📋 Directory Structure

```
data/
├── raw/                    # Original, unmodified source data
│   └── tracks_SAt_filtered_with_energetics.csv
├── processed/              # Derived datasets generated by scripts
│   ├── geojson/           # Track data in GeoJSON format for web mapping
│   ├── statistics/        # Aggregated statistics and climatologies
│   └── metadata/          # Track metadata and indices
└── external/              # Third-party or auxiliary datasets
    └── basemaps/          # Geographic boundaries, coastlines, etc.
```

## 🎯 Primary Dataset

### `tracks_SAt_filtered_with_energetics.csv`

This is the main dataset containing cyclone track information for the South Atlantic region.

**Expected location**: `data/raw/tracks_SAt_filtered_with_energetics.csv`

**Content**:
- Cyclone trajectory points (latitude, longitude, time)
- Track identification and classification
- Energetic parameters (if available):
  - Lorenz Energy Cycle components
  - Conversion terms
  - Intensity metrics
- Lifecycle information (genesis, peak intensity, decay)

**Data addition**:
```bash
# Manually place the file in the raw/ subdirectory
cp /path/to/tracks_SAt_filtered_with_energetics.csv data/raw/
```

## 📊 Data Organization Principles

### Raw Data (`raw/`)
- **Never modify**: Keep original files pristine
- **Version control**: Small files (<50MB) can be committed; larger files should use Git LFS or be documented with download instructions
- **Documentation**: Include metadata files (`.txt`, `.md`) describing provenance

### Processed Data (`processed/`)
- **Reproducible**: All files should be regeneratable from raw data using scripts in `scripts/`
- **Documented**: Include generation timestamps and script versions
- **Gitignored**: Most processed files are NOT committed (too large or regeneratable)
- **Formats**:
  - GeoJSON for web mapping
  - CSV for tabular data
  - NetCDF for gridded fields (if applicable)

### External Data (`external/`)
- Third-party datasets that complement cyclone tracks
- Examples:
  - Coastline shapefiles
  - Regional boundaries
  - Ocean basins
  - Sea surface temperature climatologies

## 🚫 Version Control Guidelines

The `.gitignore` is configured to exclude large files by default. However:

- ✅ **DO commit**: Small reference datasets, metadata files, documentation
- ❌ **DON'T commit**: Large binary files, intermediate outputs, temporary files

For large essential datasets:
1. Store externally (institutional server, Zenodo, etc.)
2. Document download/access in this README
3. Provide a script in `scripts/` to fetch them

## 📏 Data Size Management

Current guidelines:
- Files **< 10 MB**: Safe to commit directly
- Files **10-50 MB**: Consider Git LFS or compression
- Files **> 50 MB**: Use external storage; provide download script

## 🔄 Data Processing Workflow

Future pipeline (to be implemented in `scripts/`):

1. **Ingestion**: Validate and move raw data to `data/raw/`
2. **Cleaning**: Remove duplicates, handle missing values
3. **Transformation**: Convert to web-friendly formats (GeoJSON)
4. **Enrichment**: Add metadata, compute derived variables
5. **Export**: Generate application-ready datasets in `data/processed/`
