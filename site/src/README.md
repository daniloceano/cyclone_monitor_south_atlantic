# Source Code Directory

This directory will contain the main application source code for the South Atlantic Cyclone Monitor web application.

## 🎯 Purpose

The `src/` directory houses:
- Frontend application components (Next.js + React)
- Interactive map implementation (Leaflet)
- Data visualization logic
- User interface components
- Application routing and state management

## 🔄 Application Flow

1. **Authentication**: User enters password (if enabled)
2. **Data Loading**: Fetch track GeoJSON from `/data/processed/`
3. **Initial Render**: Display map with all tracks
4. **User Interaction**:
   - Apply filters (date range, intensity, region)
   - Click tracks to view details
   - Toggle visualization options
5. **Dynamic Updates**: UI responds to filter/selection changes

## 📊 Data Integration

The application will consume data generated by `scripts/`:
- **GeoJSON tracks**: `data/processed/geojson/tracks.geojson`
- **Metadata index**: `data/processed/metadata/tracks_index.json`
- **Statistics**: `data/processed/statistics/climatology.json`

## 🔒 Security Considerations

- **Password protection**: Implement basic authentication
- **Environment variables**: Never commit `.env` with real credentials
- **API routes**: Validate inputs, sanitize outputs
- **Client-side filtering**: Don't expose unnecessary data

## 📱 Responsive Design

The application should work on:
- Desktop (primary target: research workstations)
- Tablets (field work, presentations)
- Mobile (limited support: basic track viewing)

## ⚡ Performance Optimization

- **Lazy loading**: Load components on-demand
- **Data chunking**: Don't load all tracks at once
- **Memoization**: Cache expensive computations
- **Debouncing**: Optimize filter updates
